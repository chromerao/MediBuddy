# 메디버디

진료 전 준비부터 진료 후 기억 확인, 일상 실천까지 이어 주는 중장년 친화형 AI 진료 동행 서비스의 프론트엔드 MVP입니다.

## 실행

Node.js 24 이상을 권장합니다. 사용자별 저장에는 Node.js 기본 SQLite 모듈을 사용합니다.

```bash
npm install
npm run dev
```

`.env`에는 서버에서 사용할 OpenAI 설정을 추가합니다. `OPENAI_API_KEY`는 브라우저 번들에 포함되지 않습니다.

```dotenv
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-5-mini
OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe
API_PORT=8787
DATABASE_PATH=./data/medibuddy.sqlite
SESSION_COOKIE_SECURE=false
```

프로덕션 빌드와 정적 품질 검사는 다음 명령으로 확인합니다.

```bash
npm run lint
npm run build
```

## 구현된 흐름

- 직접 사용 / 가족 대리 작성 온보딩
- 음성 또는 텍스트 증상 입력
- 입력 내용 확인과 진료 준비 상태 카드 생성
- 녹음 동의와 브라우저 마이크 녹음
- 진료 후 기억 확인 퀴즈와 결과 분류
- 원본 녹음 메모리 삭제 안내
- 의료수첩 실천 체크와 한마디 건강 기록
- 가족 공유 범위 설정과 질문 카드 전송 흐름
- 글자 크기·진료 알림 설정
- 가족 초대 링크 복사와 세부 공유 범위 저장
- 초대 코드 생성, 링크 수락·취소, 연결 가족 상태의 탭 간 동기화
- 공유 설정에 따른 가족 진료 기록 조회
- 브라우저 음성 인식을 이용한 의료수첩 한마디 기록
- 진료 완료 결과의 실제 로컬 기록 누적 및 상세 조회·인쇄
- 비로그인 상태의 브라우저 로컬 저장과 최초 로그인 시 계정 저장소 이전
- scrypt 비밀번호 해시·HttpOnly 세션 쿠키 기반 회원가입, 로그인, 로그아웃
- SQLite 사용자별 의료수첩·가족 설정·화면 설정 자동 저장과 계정 간 데이터 격리
- 월간 캘린더와 일반 진료·수술·검사·시술 일정 등록, 수정, 삭제
- 홈 화면에서 가장 가까운 병원 일정과 D-Day 확인
- 서버 측 OpenAI Responses API와 구조화 출력 기반 질문 카드 생성
- OpenAI Audio API를 이용한 진료 녹음 전사와 전사 결과 확인·의료수첩 저장
- 전사 내용 기반 기억 확인 질문·정답·실천 항목 생성과 사용자 답변별 결과 분류
- 홈 화면 AI 연결 상태와 API 실패 시 안전한 로컬 폴백

## 현재 구현 범위

진료 전 증상 정리와 질문 3개 생성은 OpenAI Responses API를 사용합니다. API가 없거나 실패한 경우에만 시연용 로컬 정리 로직으로 전환됩니다. 진료 녹음은 브라우저 메모리에서 OpenAI Audio API로 전송해 한국어로 전사하며, 원본 파일은 앱 서버의 디스크나 브라우저 저장소에 저장하지 않습니다. 진료 후에는 전사에서 명확히 확인된 사실만 사용해 기억 확인 질문과 실천 항목을 만들고, 사용자의 답변을 의료수첩 결과로 분류합니다. 생성 실패 시에는 안전한 기본 질문으로 전환됩니다. 계정 기능은 현재 단일 앱 서버의 SQLite 기반 MVP이며, 실제 서비스 전환 시 관리형 인증·운영 데이터베이스, 비밀번호 재설정·이메일 인증, 계정 삭제와 의료정보 보존·삭제 정책 검증을 추가해야 합니다. 의료적 판단이나 진단·처방은 제공하지 않습니다.
